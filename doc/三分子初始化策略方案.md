# 三分子初始化与参考系

初始化定义推理时 `t=1` 的先验。E3 是固定参考系；PROTAC 只采样一份全局坐标，POI-L 子图通过当前 E3→POI 刚体变换得到对应局部表示，禁止为两个子图独立生成 ligand pose。

## 坐标约定

- E3 坐标位于 E3-local frame。
- POI 以 SE(3) 刚体位姿相对 E3 更新。
- 构建 POI-L expert 输入时，POI 与 PROTAC 必须同时变换到同一 POI-local frame。
- `tr_score` 和 `rot_score` 从 POI frame 合并回 E3 frame；torsion 是内部自由度，不旋转。
- frame round-trip、POI-local COM 和分子间相对距离是初始化的硬门禁。

## 两种实现模式

### `native`

复现 DiffDock `randomize_position` 的 PROTAC 先验：均匀随机 torsion、绕自身 COM 随机旋转、移动到 E3 COM，再叠加 `N(0, tr_sigma_max²)` 平移；当前 `tr_sigma_max=19 Å`。POI 在距 E3 30–60 Å 球壳上随机旋转和平移。

该模式适合验证 E3-L 二体路径，但组合后的 POI-L 图可能严重超出冻结 expert 的训练分布。canonical case 曾在第 5 层后激活快速放大并于第 9 层产生 NaN。`NAN_CLAMP` 只能截断激活，不能修复先验错配或保证严格 parity。

### `coupled5a`

PROTAC 与 POI 分别随机旋转，但两者 COM 都放到 E3 共同 pocket 周围 0–5 Å。PROTAC 仍随机化 torsion，因此并非从真实三元答案开始。

该模式用于当前三体 smoke/parity：canonical case 在 `NAN_CLAMP=none` 时 sub1/sub2 的 tr、rot、tor 全部 finite 并满足默认容差。三体采样入口默认使用 `coupled5a`，但实验结果仍必须记录实际模式，禁止混报。

## 回归命令

```bash
python scripts/run_sampling_parity_regression.py \
  --case 5T35_D_A_759 \
  --device cuda \
  --seed 0 \
  --init-mode coupled5a \
  --nan-clamp none \
  --out results/sampling_parity_regression.json
```

参考系检查应同时验证 cache version、POI local-center error、sub2 相对距离、frame round-trip 和旋转矩阵 determinant。任何非有限值、节点过度裁剪或 native/inline 不一致都必须阻止训练。

## 使用原则

- 二体 DiffDock parity：用 `native`，必要时固定 POI。
- 三体 Phase 1 smoke：用已通过门禁的 `coupled5a`。
- 正式比较：两种模式分别报告，不能用 coupled5a 的结果声称 native 先验已稳定。
- 不将 clamp 阈值调小作为初始化修复；若再次出现爆炸，应先检查局部坐标、cross edges 和初始 COM 距离。

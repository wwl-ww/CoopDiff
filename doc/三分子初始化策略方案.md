# 三分子初始化与参考系

## 初始化对象

初始化直接生成两个界面状态 `T_E3L` 与 `T_POL`，而不是分别放置全局 Ligand 和 POI。E3 固定；全局坐标始终由

```text
T_L   = T_E3L
T_POI = T_L · inverse(T_POL)
```

重建。这样任意 proposal 都天然对应一份一致的三元构象，并与训练的界面坐标 forward diffusion 使用相同状态定义。

## 图与参考系约束

- `sub1` 使用 E3–Ligand 图和 `T_E3L`；
- `sub2` 使用 POI-local 的 POI–Ligand 图和 `T_POL`；
- POI、Ligand、receptor crop 和 cross-edge 必须来自同一次全局重建；
- 不允许为两个 branch 各自生成互相矛盾的 Ligand pose；
- frame round trip、rotation determinant、相对距离和 finite 状态是硬门禁。

## Proposal 模式

`coupled5a` 或 pocket anchor 可以定义两个界面 pose 的先验范围，但只负责起点，不改变反向扩散语义。每次评估必须记录初始化模式、界面时间、随机 seed 和几何统计。`anchor_local` 是 near-native/local refinement proposal，不能用其高 DockQ 代替全局装配验收。

旧 `native` 模式中的 30–60 Å POI shell 不是新架构的三元先验。它可在独立二体 DiffDock 回归中使用，但不得进入 interface-coordinate 训练、采样或正式评估。

## 训练对齐

训练从真实全局结构提取两个干净界面状态，分别施加 native DiffDock forward noise，再通过刚体组合重建坐标。禁止使用以下旧路径：

- 独立扰动全局 POI 和全局 Ligand；
- 将两份全局噪声之差交给只知道 Ligand 时间的 `sub2`；
- 以 activation clamp 或 `nan_to_num` 掩盖退化图；
- 用经验 `t_anchor` 冒充 proposal 的精确 forward marginal。

若 proposal 不对应已知 forward marginal，应明确标为搜索先验，并单独报告稳定性与质量。

## 验收

初始化门禁至少检查：

- 两个界面 pose 与重建全局坐标的 round trip error；
- POI-local COM、rotation determinant 和 frame consistency；
- 两个分支的节点数、cross-edge 数与最小原子距离；
- 所有输入、expert activation 和 proposal 均 finite；
- 多 walker 各自维护完整且不共享可变坐标的状态。

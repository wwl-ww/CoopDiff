# TriCoopDiff 三分子初始化策略

> 扩散模型的初始化 = 定义 t=1 时的先验分布。初始分布决定了搜索空间的起点，直接影响收敛速度和采样质量。本文档结合多轮讨论，给出系统方案。

---

## 一、先决条件：参考系与扩散变量

在讨论初始化之前，必须先确定坐标系统。

### 1.1 参考系选择

```
全局参考系：E3 固定在原始坐标（COM=0），不参与扩散
POI：    相对 E3 的 SE(3) 刚体变换（6维：3平移+3旋转 in so(3)）
PROTAC： 全局一份坐标，同时在两个子图的参考系中有不同的表示
```

**为什么 E3 固定？**
- 消除整体平移/旋转的冗余自由度（SE(3) 不变性）
- E3 连接酶种类少（VHL、CRBN），作为参考系最自然
- PROTAC 设计中 E3 binder 通常是已知且固定的
- 与 DiffDock 的惯例一致（蛋白固定，配体运动）

### 1.2 扩散变量

| 自由度 | 符号 | 维度 | 负责模块 | 描述 |
|--------|------|------|---------|------|
| PROTAC 平移 | t_q | 3 | DiffDock（二体） | 配体质心相对蛋白的位移 |
| PROTAC 旋转 | R_q | 3 (so(3)) | DiffDock（二体） | 配体整体旋转 |
| PROTAC 二面角 | χ | K（可旋转键数） | DiffDock（二体） | 配体内部柔性自由度 |
| E3-POI 刚体变换 | SE3 | 6 (3平移+3旋转) | TriBrain（三体） | 蛋白-蛋白相对位姿 |

> 注意：PROTAC 在两个子图中各有自己的"局部表示"（子图1=相对E3，子图2=相对POI），但物理上是同一个分子。子图2中的 PROTAC 坐标由 `T_E3→POI` 变换计算，不需要独立初始化。

## 二、PROTAC 坐标同步机制

两个子图物理断开但共享 PROTAC。关键实现细节：

```
❌ 错误做法：
  子图1 独立采样 PROTAC 初始坐标
  子图2 独立采样 PROTAC 初始坐标
  → 两个子图的 PROTAC 坐标不一致，合并时乱套

✅ 正确做法：
  全局采样一次 PROTAC 初始坐标（相对 E3 参考系）
  子图1 直接使用
  子图2 通过 T_E3→POI 的当前估计进行坐标变换得到 PROTAC_POI
  
  扩散过程中每步更新：
  - 子图1 输出 s_q1 → 更新 PROTAC 坐标（在 E3 参考系中）
  - 子图2 输出 s_q2 → 与 s_q1 加和 → 统一更新 PROTAC 坐标
  - TriBrain 输出 s_SE3 → 更新 T_E3→POI → 子图2的PROTAC坐标随之更新
```

## 三、四种初始化方案

### 方案 A：球壳随机初始化（推荐默认）

**核心思路**：t=1 代表"合理范围内的最大不确定度"，不是全空间的完全随机。所有自由度在设定的合理范围内均匀采样。

| 组件 | 自由度 | 初始化分布 | 范围/参数 |
|------|--------|-----------|----------|
| **E3** | — | 固定在原点 | — |
| **PROTAC** | 平移 | E3 口袋中心为球心的球壳内均匀采样 | 球壳半径：±10Å（无口袋先验时扩至 ±20Å） |
| | 旋转 | IGSO(3) 各向同性均匀分布 | 全角度 |
| | 二面角 | 均匀分布 | [-π, π] |
| **POI** | 平移 | E3 质心为球心的球壳内均匀采样 | 球壳内半径 30Å，外半径 60Å |
| | 旋转 | IGSO(3) 各向同性均匀分布 | 全角度 |

**为什么是球壳？**
- 内半径 30Å：避免初始就穿模（蛋白直径 ~30-50Å）
- 外半径 60Å：20 步扩散能收敛的最大范围（经验值，需调参验证）
- 和内半径 0 的"实心球"不同——球壳保证 POI 不会一开始就在 E3 旁边（那等于给答案）
- PROTAC 在口袋附近：这是 DiffDock 的标准做法——配体"知道"目标蛋白在哪，但具体 pose 未知

**为什么不在 PROTAC 附近初始化 POI？**
- t=1 应该是 POI 的最大不确定状态
- 如果初始化就靠近 PROTAC，等于加强了"POI 必须从 PROTAC 方向靠近"的先验
- 球壳保留了 POI 可以从任何方向靠近的可能性
- 物理上对应"只知道 E3 和 PROTAC，不知道 POI 会从哪个方向、多远的地方过来"

**优点**：平衡收敛性和多样性，扩散对接的标准做法（源自 DiffDock）
**缺点**：球壳超参数（30-60Å、±10Å）需要经验调优
**适用场景**：默认方案，所有场景

---

### 方案 B：自适应范围初始化（带先验分层，最优）

**核心思路**：根据先验知识的可用性，自动调整初始化范围。先验越强，初始化范围越集中。

| 先验级别 | PROTAC 平移范围 | POI 平移范围 | 场景 |
|---------|----------------|-------------|------|
| **L1 已知**（口袋残基已标注） | E3 口袋中心 ±10Å | E3 质心 30-60Å 球壳 | 有共晶结构的标准 PROTAC |
| **L2 已知**（只知 E3/POI 大致结合区域） | E3 全表面 ±20Å 球壳 | E3 质心 20-70Å 球壳 | 有口袋预测但无共晶结构 |
| **L0 无先验**（全新靶点） | 相对 E3 的全表面球壳 (±30Å) | E3 质心 20-80Å 球壳 | 盲对接 |

**与口袋引导的配合**：
- 有引导（α>0）：初始化用 L1/L2 范围，引导作为额外漂移项加速收敛
- 无引导（α=0）：初始化用 L0 范围，仅靠扩散 sampling 找到正确位置
- 两者不是替代关系——初始化设定起点，引导提供漂移方向

**优点**：最灵活，充分利用可用先验，无先验时自动放宽范围
**缺点**：需要实现先验级别的自动判断逻辑
**适用场景**：生产环境，需要适配多种输入条件

---

### 方案 C：二体对接结果初始化（快速模式）

**核心思路**：先分别跑 E3-PROTAC 和 POI-PROTAC 的二体对接（用冻结的 DiffDock），把对接结果作为 t=1 的起点加噪声。

```
1. DiffDock 跑 E3-L 二体对接 → PROTAC 在 E3 口袋中的 pose
2. DiffDock 跑 POI-L 二体对接 → PROTAC 在 POI 口袋中的 pose
3. 两个 PROTAC pose 对齐（Kabsch 对齐 warhead 原子）→ 得到初始 POI 位姿
4. 在此基础上加 t=1 噪声 → 开始三体扩散
```

**优点**：起点非常好，收敛极快（可能 10 步就够），接近端到端
**缺点**：
- 不是真正的端到端——依赖二体对接质量
- 如果二体对接结果有偏差（比如 warhead pose 在二元和三元中不同），初始化就错了
- 失去了"从无到有"的扩散美感
- 多 walker 的多样性可能不够——起点太接近

**适用场景**：快速推理模式、已知二体 pose 很准确时、高通量初筛

---

### 方案 D：全空间随机初始化（不推荐）

**核心思路**：PROTAC 和 POI 在整个空间内均匀随机采样（完全盲）。

**为什么不推荐？**
- 20 步扩散绝对不够——蛋白相距 100Å+ 时，二体专家各看各的，score 信号完全无法指导蛋白靠近
- DiffDock 等成熟方法都不这样做——它们都在蛋白附近初始化配体
- 如果真想盲对接，需要 100+ 步扩散 + 更强的物理约束，不是 MVP 的范围

**适用场景**：仅作为理论对照，证明"球壳初始化是必要的工程权衡"

---

### 方案 E：晶体扰动初始化（不推荐，仅用于测试）

**核心思路**：从真实三元结构出发，加小幅度噪声作为初始化。

**为什么不推荐？**
- 严重过拟合——等于告诉模型答案
- 失去了泛化能力——真实场景中我们没有三元结构
- 论文中可以用作"oracle 上限"来展示模型能力的天花板

**适用场景**：仅用于消融中的"upper bound"对照

---

## 四、方案排序与推荐

```
从"最推荐"到"最不推荐"：

1. 🥇 方案 B（自适应范围）：最灵活，适配所有先验级别，生产环境首选
2. 🥈 方案 A（球壳随机）：简单、标准、鲁棒，MVP 默认方案
3. 🥉 方案 C（二体对接初始化）：快速模式，适合高通量场景
4. ⚠️ 方案 E（晶体扰动）：仅用于 upper bound 消融
5. ❌ 方案 D（全空间随机）：不推荐，20 步无法收敛

MVP 阶段：用方案 A（球壳随机）
完整版：用方案 B（自适应范围）+ 方案 C（快速模式选项）
```

## 五、训练 vs 推理的初始化差异

| | 训练 | 推理 |
|---|------|------|
| **初始化** | 不直接初始化——每个 batch 从真实结构出发，随机加噪声到扩散步 t | t=1 时从先验分布采样初始坐标 |
| **分布来源** | 训练数据的经验分布 + 噪声 | 手动定义的先验分布 |
| **多 walker** | 不需要（每个训练样本独立采样噪声） | 需要（不同随机 seed → 不同初始坐标和噪声路径） |

**训练时的关键细节**：
- 物理损失是对去噪后的坐标计算的——这意味着噪声水平 t 越大，物理损失越弱（因为去噪后坐标的确定性越低）
- 这和多速率 λ 的衰减是协调的：早期 λ 大 → 噪声大 → 物理损失弱 → 让模型自由探索；晚期 λ 小 → 噪声小 → 物理损失强 → 精细约束

## 六、初始化验证方法

| 诊断指标 | 合理范围 | 说明 |
|---------|---------|------|
| **收敛率** | >90% 的 walker 最终在 E3-POI 距离 < 80Å | 如果大量 walker 蛋白离得很远 → 初始范围太大或扩散步数不够 |
| **最终位置聚集性** | 32 个 walker 的最终 POI 位置聚类有明显的主簇 | 如果完全随机 → 没收敛 |
| **t=1 能量** | 很高（穿模、拉伸） | 正常，t=1 就是全噪声 |
| **能量下降曲线** | 随 t 减小单调下降 | 如果不降反升 → 初始化或 score 有问题 |
| **初始距离 vs 最终距离** | POI 从 30-60Å 球壳收敛到晶体结构 ±5Å | 验证收敛效率 |
| **DockQ 的 seed 间方差** | 32 walker 的 DockQ 标准差 < 0.1 | 方差太大 → 初始化不够稳定 |

## 七、实现检查清单

- [ ] E3 固定在原点，不参与扩散
- [ ] POI 平移用球壳初始化（内半径 30Å，外半径 60Å），不是实心球
- [ ] POI 旋转用 IGSO(3) 均匀分布，不用欧拉角（避免 gimbal lock）
- [ ] PROTAC 初始化坐标在两个子图中一致（全局采样一次）
- [ ] 有口袋先验时缩小 PROTAC 平移范围，无先验时扩大
- [ ] 训练时不手动初始化——从真实结构加噪声
- [ ] 推理时 32 walker 用不同随机 seed 初始化
- [ ] 多速率 λ 的衰减与初始化范围协调（λ 归零时对应自由度收敛到初始化范围的中心）

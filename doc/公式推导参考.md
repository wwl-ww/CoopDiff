# 界面坐标公式参考

## 状态定义

固定 E3 全局位姿为单位元。令 `T_E3L` 表示 E3 到 Ligand 的相对刚体，`T_POL` 表示 POI 到 Ligand 的相对刚体，均属于 SE(3)。Ligand 和 POI 的全局刚体为：

```text
T_L   = T_E3 · T_E3L = T_E3L
T_POI = T_L · inverse(T_POL)
```

因此两个界面状态唯一确定一致的三元全局构象。实现必须使用刚体群乘法与逆，不能分别对 translation 和 rotation 做符号近似。

## Forward diffusion

训练为两个界面独立采样 native DiffDock 噪声：

```text
T_E3L,t = Noise_DD(T_E3L,0; t_E3L)
T_POL,t = Noise_DD(T_POL,0; t_POL)
```

随后由上述组合式重建 `T_L,t` 与 `T_POI,t`。独立的是两个**相对界面的 forward noise**，不是全局 Ligand 和全局 POI 的两个互不协调扰动。每个 expert 使用对应界面的 `t`、sigma 和监督目标。

Ligand torsion 是共享内部自由度。两个 expert 可各自产生 torsion score，反向步使用：

```text
s_tor = 0.5 * (s_tor_sub1 + s_tor_sub2)
```

并且每步只应用一次。

## Reverse update

`sub1` 的刚体 proposal 作用于 `T_E3L`，从而直接更新 `T_L`。随后 `sub2` 的 proposal 作用于 `T_POL`；在保持更新后 Ligand 固定的条件下，通过

```text
T_POI,new = T_L,new · inverse(T_POL,new)
```

得到 POI 的新全局位姿。该顺序使两个 expert 各自控制一个明确界面，并避免把两个相对 score 当作同一坐标上的向量相加或插值。

## 等变性与不变量

对任意全局刚体 `G`，同时左乘所有全局构件不会改变 `T_E3L` 与 `T_POL`；重建结果相应左乘 `G`。测试至少应覆盖：

- `T · inverse(T)` 为单位元；
- 相对状态到全局状态再返回的 round trip；
- 全局 SE(3) 变换下的等变性；
- `sub1` 更新时 POI–Ligand 界面状态不被隐式重解释；
- `sub2` 更新时 Ligand 全局位姿严格保持不变。

## 模型边界

DiffDock expert 负责两界面刚体和 torsion proposal。TriBrain 只通过 branch-specific FiLM 调节 expert 内部特征，并输出 scalar auxiliary predictions。模型没有 merge gate、直接坐标 residual head 或独立 SE(3) score head；这些旧参数化不能与界面坐标扩散混用。

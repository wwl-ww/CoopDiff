# TriCoopDiff vs DeepTernary：竞争定位、贡献与实验计划

> 关联文档：[[TriCoopDiff 模型交接文档]]（当前 v2.4，本文档架构描述以 v2.4 为准）
> 最后更新：2026-07-31 | 版本：v2.1（基线值与架构措辞于 2026-08-13 回改，见 [[DeepTernary 审计完成交接文档]]）

---

## 一、一句话定位

**DeepTernary 是结构预测工具，TriCoopDiff 是带物理约束的扩散生成模型——不仅预测结构，还输出构象系综用于功能排序（协同性趋势、生产性概率等）。**

核心创新不是"物理建模 vs 纯学习"，而是**预训练二体专家的高效零样本复用 + 轻量协调网络实现三体效应 + 系综用于功能排序**。

---

## 二、核心创新（诚实提炼版）

### 方法创新

| 创新点 | 具体内容 | 为什么新 |
|--------|---------|---------|
| **物理断开的双子图 + 全局协调网络** | 二体专家拆成两个独立子图（E3-L 和 POI-L），输入分布零 OOD；TriBrain 在完整三分子连通图上从头学习全局协调，通过逐层 FiLM 调制二体特征 | 每个组件不新，但**这个特定的架构组合**——冻结二体专家分别前向 + 独立完整图上协调 + 逐层 FiLM 调制——是新的 |
| **预训练二体专家零 OOD 复用** | DiffDock 20M 参数冻结，不做任何微调，两个子图输入与预训练时 100% 一致 | 现有 PROTAC 方法要么从头训（DeepTernary）、要么双专家拼接后融合——都不是输入分布零 OOD 的冻结复用 |
| **小样本友好** | 仅 2M 可训参数，数千通用三元复合物预训练 + ~50 PROTAC 微调即可 | 比从头训练 20M+ 参数的方法数据效率高一个数量级 |

### 应用创新

| 创新点 | 具体内容 | 为什么新 |
|--------|---------|---------|
| **扩散系综用于 PROTAC 功能排序** | 多 walker 独立扩散 → 构象系综 → 布居比 → 协同性趋势排序、生产性概率 | 之前没有人把扩散模型的构象系综和 PROTAC 协同性预测联系起来 |
| **结构预测 + 功能排序一体化** | 同一模型同时输出结构和功能指标，不需要额外对接/打分步骤 | 现有方法结构归结构、功能归功能（对接后 MM/PBSA 或 MD） |

## 三、与 DeepTernary 的对比（更新版）

### 3.1 两个模型是互补关系，不是替代关系

| 维度 | DeepTernary | TriCoopDiff |
|------|-------------|-------------|
| **定位** | 结构预测工具 | 带物理约束的扩散生成模型 |
| **核心输出** | 单结构 + PAE | 构象系综 + 功能排序 + 结构 |
| **推理速度** | ~7 秒 | 较慢（扩散 20 步 × 32 walker） |
| **适用场景** | 高通量筛选、快速评估能否形成三元复合物 | Lead optimization、linker 优化、协同性分析 |
| **优势** | 速度快、pipeline 简单、已发表 | 功能排序、系综分析、物理合理性保证 |
| **局限** | 刚性对齐 + 单结构 → 无系综信息、无功能预测 | 速度慢、工程复杂度高、尚未发表 |

### 3.2 结构预测：正面比较

| 指标 | DeepTernary（已发表） | TriCoopDiff（目标） | 备注 |
|------|----------------------|-------------------|------|
| 全局 DockQ | 0.6588（本地审计） | ≥ 0.66（FT 版本） | 论文声称 0.65；审计 0.6588 为唯一对比基线 |
| 长 linker DockQ（>15 可旋转键） | 未报告 | 目标比 DeepTernary 高 0.05~0.10 | 双子图迭代精修在长 linker 上有结构性优势 |
| 空间冲突率 | ~0.01%（已审计） | <1%（后处理修正后） | 物理后处理保证物理合理性 |

### 3.3 功能排序：护城河

| 指标 | DeepTernary | TriCoopDiff | 说明 |
|------|-------------|-------------|------|
| 协同性 α 排序 | 只能 BSA-活性 post-hoc 相关 | Spearman ρ > 0.6（排序预测） | 从系综布居比做排序，非定量自由能 |
| Hook 效应拐点排序 | ❌ | Spearman ρ > 0.5（排序预测） | 二元/三元竞争建模，样本少所以目标保守 |
| 生产性构象概率 | ❌ | AUROC > 0.75（判别有/无活性） | 赖氨酸-E2 距离在系综中的分布 |
| Linker 优化 | 枚举 + 打分，口袋点预测不一致 | 同体系不同 linker，直接比较 ΔG 趋势 | — |

## 四、贡献（修正版）

### 贡献 1：迭代精修替代刚性拼装

DeepTernary 的刚性对齐是一次性的。TriCoopDiff 在扩散过程中所有自由度联合迭代精修——warhead pose、linker 构象、蛋白刚体姿态在 20 步去噪中同时更新。TriReflect（后处理）消除残留的硬物理错误。

### 贡献 2：预训练二体专家的输入分布零 OOD 复用

DiffDock（20M）冻结，拆成两个物理断开的独立子图分别前向——输入与预训练时 100% 一致。TriBrain（2M）通过逐层 FiLM 调制二体特征（标准 ControlNet/LoRA 范式），不修改专家参数。消融实验验证 FiLM 调制是否导致二体能力退化。

### 贡献 3：物理后处理 + 引导势先验

扩散结束后物理硬规则检测（VDW、键长键角、二面角）→ 局部能量最小化修正。口袋信息作为模拟退火式引导势（α·t 衰减），无先验时 α=0 自动退化。注：口袋引导会改变采样分布（引导等价于引入偏置项），α 是搜索效率和分布偏移的杠杆。

### 贡献 4：构象系综支持功能排序

多 walker 独立扩散 → 构象系综 → 布居比 → 协同性排序、生产性概率。定位为排序预测（非定量自由能），需要实验验证扩散系综与玻尔兹曼分布的定性对应关系。

## 五、实验计划（更新版）

### Phase 1：DeepTernary 审计（确认基线）

**目标**：用 DeepTernary 开源代码+权重，在 PROTAC benchmark 上测它没报告的指标。

| 指标 | 目的 |
|------|------|
| DockQ 复现 | 确认 0.6588 基线（已完成，08-09） |
| **空间冲突率** | 刚性对齐后是否有显著冲突残留 |
| **Linker 应变能分布** | 长 linker 上是否偏高 |
| **40 seed 收敛性** | 多样性和打分可靠性 |
| **按 linker 长度/界面大小分层的 DockQ** | 找到它系统性垮掉的子集 |

### Phase 2：TriCoopDiff 结构预测验证

| 指标 | 目标 | 版本 |
|------|------|------|
| 全局 DockQ | ≥ 0.66 | FT |
| 长 linker 子集 DockQ | > DeepTernary +0.05~0.10 | FT |
| 空间冲突率（后处理修正后） | < 1% | FT |
| Linker 键长键角异常率 | < 1% | FT |

**消融实验（核心消融）**：

| 消融 | 目的 |
|------|------|
| 无 TriReflect（纯扩散输出） | 验证后处理修正的增益 |
| 无口袋引导（α=0） | 验证引导的有效性 |
| 单速率扩散（λ=1.0） | 验证多速率 trick 是否有增益 |
| L0→L1 注入（无 FiLM → 逐层 FiLM） | 验证 FiLM 调制是否必要 |
| **原始特征 vs 二体专家特征** | 验证 TriBrain 独立特征是否够用 |
| **加和 vs 直接输出** | 验证 score 加和的归纳偏置是否有价值 |

> 新增消融（回应豆包批评）：原始特征 vs 二体专家特征是验证 TriBrain 独立设计的核心实验；加和 vs 直接输出是验证 score 加和假设的核心实验。

### Phase 3：功能排序验证

| 实验 | 指标 | 样本量 | Baseline |
|------|------|--------|---------|
| 协同性 α 排序 | Spearman ρ > 0.6 | ~200 个 | BSA-活性相关（DeepTernary） |
| Hook 效应拐点排序 | Spearman ρ > 0.5 | ~20-30 个 | — |
| 生产性构象判别 | AUROC > 0.75 | ~20-30 对 | 传统对接打分（Vina/Glide） |
| Linker 长度-协同性曲线 | 极值点 MAE、Kendall τ | ~3-5 系列 | — |

> 功能排序的公平 baseline：DeepTernary 不能做功能预测，所以 Phase 3 的公平 baseline 是传统对接打分方法（Vina、Glide、MM/PBSA）——这些也是结构预测 → 打分 → 排序的 pipeline。

### Phase 4：难例压力测试

| 难例类型 | 预期优势 |
|---------|---------|
| 全新 linker 化学型 | 物理后处理泛化好 |
| 显著诱导契合 | 扩散采样 + 门控微调 |
| 多 warhead binding mode | 复本交换（如实现）或独立 walker 自然采样 |
| 新 E3 连接酶 | 物理约束 + 预训练专家泛化 |

## 六、论文叙事结构（修正版）

```
1. Introduction
   - PROTAC 设计需要结构预测，但更需要功能层面的排序和指导
   - 现有方法：DeepTernary 做结构、传统对接打分做排序——各做各的
   - 我们的贡献：在同一扩散框架中同时完成结构预测和功能排序

2. TriCoopDiff 方法
   - 核心创新：预训练二体专家的高效零样本复用 + 轻量协调网络
   - 双子图冻结二体专家（输入分布零 OOD）
   - TriBrain 全局协调（独立完整图 + 逐层 FiLM 调制）
   - 多速率扩散（工程 trick，消融验证）
   - 物理后处理修正（硬规则 + 局部能量最小化）
   - 口袋引导（模拟退火式先验，α·t 衰减）
   - 系综用于功能排序（布居比 → 协同性趋势、生产性概率）

3. 实验
   3.1 结构预测精度（DockQ / RMSD）
       - 全局与 DeepTernary 可比（FT 版本）
       - 困难子集（长 linker）显著超过
       - 消融验证各模块贡献
       - 新增消融：原始特征 vs 二体专家特征、加和 vs 直接输出

   3.2 物理合理性
       - 冲突率、linker 几何的定量比较
       - DeepTernary 审计结果（客观数据，不是猜测）

   3.3 功能排序（与 DeepTernary / 传统对接方法比较）
       - 协同性趋势排序
       - 生产性构象判别
       - Linker 长度优化
       - Hook 效应拐点排序

4. Discussion
   - 诚实讨论局限性：扩散 t 不是物理时间、自由能是排序非定量、采样量限制
   - 为什么这个架构组合比单纯的结构预测更适合 PROTAC lead optimization
   - 未来：更准确的自由能计算、更大规模的实验验证
```

## 七、风险与应对（更新版）

| 风险 | 可能性 | 应对 |
|------|--------|------|
| FT 版全局 DockQ 低于 0.66 | 低 | 叙事改为"结构精度可比，功能排序独特"；困难子集可能仍然显著超 |
| TriBrain 独立特征容量不足 | 中 | 消融验证：原始特征 vs 拼二体专家特征。如果后者显著好 → 牺牲独立性换性能 |
| Score 加和假设不成立 | 中 | 消融验证：加和 vs TriBrain 直接输出 s_q。如果直接输出更好 → 放弃加和形式 |
| 通用三元→PROTAC zero-shot 差 | 中高 | 主推 FT 版本（~50 PROTAC 微调），Zero 版作为 bonus |
| 扩散系综与玻尔兹曼分布关系不清 | 中 | 全部功能预测定位为"排序"而非"定量"，诚实标注为假设 |
| 复现 DeepTernary 遇工程困难 | 低中 | 用官方 checkpoint + predict.py，不做重训 |
| 推理速度慢 | 中 | 定位在 lead optimization（不是高通量筛选），诚实讨论 speed-accuracy tradeoff |
| 功能预测样本太少 | 中高 | 降低统计预期（Spearman ρ 代替 Pearson R），明确标注样本量限制 |

## 八、与 v1.0 竞争定位文档的主要差异

| 维度 | v1.0 | v2.1 |
|------|------|------|
| 核心定位 | 物理建模工具 | 带物理约束的扩散生成模型 |
| 核心创新 | 扩散模拟结合动力学 | 预训练二体专家复用 + 轻量协调 + 系综排序 |
| 功能预测 | 定量（Pearson R > 0.7） | 排序（Spearman ρ > 0.6） |
| Hook 效应 | 浓度预测 | 拐点排序 |
| 复本交换 | 核心采样算法 | 实验性可选模块 |
| 物理合理性 | 三层硬约束 | 后处理修正 |
| Zero-shot | 作为卖点 | 存在 gap，FT 版为主推 |
| 和 DeepTernary 关系 | "我们的方法能打败它" | "结构层面可比，功能排序是独特价值" |
| 公平 baseline | 只有 DeepTernary | 结构：DeepTernary；功能：Vina/Glide/MM-PBSA |

# 采样保真度与 Native Parity

本文是已完成调查的最终摘要。历史假设、agent brief 和中间 patch 已合并后删除。

## 验证目标

零 FiLM、零 merge gate 时，inline expert 必须在同一张图、同一时刻和同一初始化 pose 上复现 native DiffDock 的 tr、rot、tor 输出。默认容差为 `atol=1e-5`、`rtol=1e-4`，且所有张量必须 finite。

## 已修复差异

- PROTAC torsion σ 与 temperature sampling 对齐 native sampler。
- 初始化绕 E3 receptor COM，而不是 ligand template COM。
- E3/POI/PROTAC 的真实相对平移在 featurization 后得到保留。
- POI-L 分支将 receptor 与 ligand 一起转换到 POI-local frame。
- dynamic crop、cross cutoff、时间 embedding 和逐层 clamp 的调用顺序与 native 路径一致。
- score 合并改为 residual gate：`s_q=s_q1+g(s_q2-s_q1)`，零初始化时 `g=0`。

## 根因结论

canonical sub2 的 NaN 不是 native/inline 算子语义差异。`native` 三体初始化把 POI 放在 30–60 Å 球壳，同时给 PROTAC 叠加约 19 Å 高斯位移，形成冻结 POI-L expert 的 OOD 图。激活从第 5 层开始爆炸，第 8 层约 `2.1e29`，第 9 层首次变为 NaN。

设置 clamp=100 虽可数值通过，但会改变 expert 行为；clamp=10000 下微小浮点差异仍被后续层放大。因此 clamp 不是根因修复。使用 `coupled5a` 后，即使 `NAN_CLAMP=none`，两条分支均 finite 且 parity 通过。

## 变更后的必跑门禁

修改 `diffusion.py`、`sampler.py`、`model.py`、`graphs.py`、expert/FiLM 或参考系逻辑后，必须重跑：

```bash
python scripts/run_sampling_parity_regression.py \
  --case 5T35_D_A_759 --device cuda --seed 0 \
  --init-mode coupled5a --nan-clamp none --nan-trace \
  --out results/sampling_parity_regression.json
```

失败时记录每层 finite/absmax、ligand/receptor node 数、cross edge 数、局部 COM 和初始化中心距离；不要先调整 clamp 掩盖问题。

## 算法原理与模型架构审查（当前重点）

用户明确要求审查算法原理与模型架构。前两轮偏重实现接口，以下分析作为本文主要结论；后续工程问题保留为历史记录，不作为算法能力的替代判断。

### A. 先明确当前模型究竟在学什么

当前生产路径可以写为：

\[
s_{k+1}=\operatorname{LegalUpdate}\big(s_k,u_\theta(s_k,t_k,\Delta t)\big),
\qquad
\min_\theta\mathbb E_{c,z}\,\ell\big(s_K(c,z),y_c(z)\big).
\]

其中固定 E3，状态包含 ligand、POI 和刚体参考信息；动作是 ligand／POI 各自的平移、旋转与 ligand torsion。两个冻结 Matcha 为动作网络提供条件化节点特征，执行 K=20 步后监督真实终点。配体标签是初始构象对应的可达投影，POI 标签为 native。

依据：`train.py:744–774`、`sdpi_flow.py:133–159`、`models/assembly.py:488–539`。

**这在算法上是有限时域装配控制／终点回归。** 当前目标没有 score matching，也没有 flow matching 的中间速度监督；不能仅凭历史类名和时间变量，就认为它已经学到了正确的扩散逆过程、概率密度或平衡构象分布。这不意味着方法无效，但应按装配控制器评估其能力。

### B. 最关键的目标缺口：正确终点不保证稳定收敛

训练只看 rollout 终点，near-target 辅助入口也只看其 20 步或 4 步后的终点，没有要求 native 状态处动作接近零，也没有要求每一步接近目标或保持界面。

因此以下三个命题不同：

1. K 步之后回到正确结构；
2. 正确结构是运动场的不动点；
3. 正确结构附近是稳定吸引域。

当前终点监督直接约束第一项，不能推出后两项。对附近起点取得较低终点 loss 也不足以证明逐步收敛。

**严格反例，已用实际 `SDPIFlow.rigid_step` 验证：** 令合法刚体动作始终绕 z 轴旋转，角速度为 \(10\pi\) rad/time，平移和 torsion 为零。取当前 \(\Delta t=0.05\)，20 步转五圈、4 步转一圈，均精确回到初始 native 结构，但第一步已经转了 90°。两种 near-target 时长都不能排除该运动。

三点非共线配体的 CPU float64 实验结果：

| 执行步数 | 终点 RMSD | 首步 RMSD | 路径最大 RMSD |
| --- | --- | --- | --- |
| 20 | 5.13e-15 Å | 1.633 Å | 2.309 Å |
| 4 | 1.03e-15 Å | 1.633 Å | 2.309 Å |

这是监督目标允许的反例，不是声称当前网络已经学到了循环。它严格说明“near-target 终点成功”不等于“保持正确结构”。

**实际风险：** 模型可以依赖固定步数、阶段时钟和轨迹抵消取得低 loss；在新起点、动作扰动或执行时长变化下未必保持稳定。20 步反传还把早期搜索行为的信用分配完全交给最终误差。

**优先诊断：** 在 native／近 native 状态测单步动作及界面破坏量，记录沿途误差和每步角度；测试小扰动后的误差是否收缩。先测出问题，再决定是否加入不动点约束或阶段性监督，不应盲目叠加所有中间 loss。

### C. 专家迁移的核心取舍：迁移了节点特征，没有迁移显式刚体场

`expert.py:294–299` 用 Matcha 的两个专用 token 计算平移、旋转，却只将 `lig_tokens[0,2:]` 及 protein tokens 作为节点标量交给三元网络。`assembly.py:529` 从专家 proposals 消费的只有 torsion；刚体动作由新训练的 `LegalPoseDecoder.rigid` 独立产生。

因此当前结构不是两个预训练刚体运动场的直接协同，而是“两个冻结特征提取器＋新学习的三元刚体控制器”。这避开了两个二元建议彼此冲突的问题，同时也放弃了预训练刚体头的显式引导和专用 token。

此外，Matcha 的五通道向量为：

\[
v_i=\big((x_i-c_P)/10,\;(x_i-c_L)/10,\;e_1,\;e_2,\;e_3\big),
\]

见 `expert.py:309–318`。它们是坐标和蛋白规范帧构成的几何基底，不依赖专家权重、阶段或 FiLM，不能称为预训练模型学出的向量运动知识。

**能力边界：** 三个帧轴已提供完整三维基底，因此不能说解码器无法表达任意方向；节点 tokens 也可能包含足够运动信息。真正需要验证的是三元网络重新解码这些知识的样本效率，以及当前专家是否实际贡献了泛化收益。

**最少消融：** 保留完全相同的几何向量，将专家 scalar 置零，与当前模型配对训练；如果专家收益成立，再比较加入刚体专用 token 或小门控 prior。不要预设直接加入二元运动一定更好。

### D. 二元条件接口存在压缩，且专家阶段与实际状态可能错位

`assembly.py:614–653` 将对侧蛋白及 ligand 通过注意力加权均值、距离矩和接触密度压缩到每个接收蛋白节点，再通过

\[
h'_i=h_i(1+\gamma_i)+\beta_i,\qquad
|\gamma_i|,|\beta_i|\le0.1
\]

调制冻结专家的 protein embedding。该接口并未让冻结专家直接对完整对侧节点做交互。均值与少量矩不能唯一表示任意对侧构型；幅度上限进一步限定了调制强度。不过后端三元 controller 仍读取全部节点和方向，不能把这写成整个模型无法看到对侧几何，也不能单凭 0.1 的输入幅度推断最终影响必然微弱。

另一方面，`expert.py:36–42` 按全局时钟切换三个专家。三元网络的状态并不由专家自己的流产生，阶段切换时没有保证当前几何符合下一个专家的预训练分布。

**风险假设：** 真正协同可能主要由后端完成，而冻结专家没有充分适配三元条件；宽初态时还可能过早进入后期专家，读到分布外证据。

**优先诊断：** 记录 FiLM 饱和率、条件梯度及阶段边界处证据／动作变化；先比较“条件 FiLM 开／关”的配对结果，再决定是否需要更强接口或阶段混合。

### E. 可达投影改变了科学目标，不能仅以低终点 loss 判断成功

投影求解器最小化初始构象可达集合与晶体配体之间的全原子坐标残差，见 `initialization/endpoints.py:180–187,424–440`。可表示为：

\[
\tilde L_z\approx\arg\min_{L\in\mathcal M_z}
\sum_i\|L_i-L_i^*\|^2.
\]

这里是数值局部求解，不保证全局最优。集合 \(\mathcal M_z\) 保留该初始构象的键长、键角及刚性片段。投影保证目标与运动自由度相容，但优化目标没有单独要求两端 warhead 的真实接触或化学结合几何保持。

之后训练甚至用 \(\tilde L_z\) 定义配体界面接触。因此，当投影误差不可忽略时，零训练误差对应的是替代结构，不再是晶体结构；全配体平均误差小也不保证两个结合端都准确。

**潜在瓶颈：** 对长 linker，整体拟合可能牺牲关键端基；初始环构象或刚性片段错误也无法靠当前 torsion 动作修正。后者是动作空间限制，不能用加深 controller 自动解决。

**优先诊断：** 按投影残差分桶，分别报告两端 RMSD／接触恢复和 linker 误差，区分“目标本身不可恢复”与“网络没有到达已有目标”。只有发现端基确被投影牺牲，才考虑带结合端权重或约束的投影。

### F. 合法内部几何不等于物理有效的三元装配

刚体＋torsion 更新保留局部键几何，但不保证 ligand 不自碰撞、不穿入蛋白侧链。训练的两侧接触主要是 CA–ligand 8 Å 几何，跨组分排斥也是 CA 级粗粒度项，见 `train.py:377–420`。标准入口默认 steric weight 为 0.05；即使启用该项，也不是全原子体积排斥。

从可辨识性看，相同 CA 位置可以对应不同侧链构象，CA 接触与排斥不能区分这些环境的不同碰撞情况。POI 又只能刚体移动，无法修复需要侧链或主链诱导契合的输入。

此外，continuous-horizontal torsion 通过起点切向量计算去自旋，再执行有限扭转，见 `sdpi_flow.py:285–320`。因此刚体与 torsion 的解耦是局部意义，不能推断有限大角步严格无刚体残余；当前角速度也没有硬上限。

**优先诊断：** 对已有输出检查全原子 clash、配体内部远程碰撞以及每步最大扭角。若大角步普遍存在，再用执行器子步验证有限步误差；若主要是侧链碰撞，应讨论表示／自由度，而不是仅增加 CA 排斥权重。

### G. 单 native 回归与多模态生成是不同任务

固定 case 的 POI 目标为 \(P^*\)，随机初始化为 z，则当前平方坐标项满足：

\[
\mathbb E_z\|F_\theta(z)-P^*\|^2
=\|\mathbb E_zF_\theta(z)-P^*\|^2
+\operatorname{tr}\operatorname{Cov}_z(F_\theta(z)).
\]

这说明在均值误差相同的条件下，目标奖励终点方差缩小。随机 walker 并不自动提供多模态概率监督，更不能直接解释为平衡构象群或结合自由能。

如果目标就是寻找一个正确 native，收缩合理，不是 bug。如果目标包括构象多样性或协同性分布，则当前训练原则不足。也不能反向声称“MSE 必然输出非法平均结构”：初始化 z 是模型输入，且执行器约束了坐标流形。

另一个条件性问题是原子标签对称性：配体坐标损失和投影未显式在化学图自同构下求最小值。对称等价 pose 可能被惩罚，是否影响本数据需比较固定标签与 symmetry-aware RMSD，不能仅凭存在对称分子就断言训练失败。

### H. 最佳蛋白界面不等于最佳三元模型

训练确实包含两个配体界面，但 `best_model.pt` 按蛋白–蛋白全原子 DockQ 选择，见 `scripts/train_entry.py:427–439`。该 DockQ 不使用配体坐标，数学上选模指标为 \(Q(P,L)=Q(P)\)。所以相同蛋白装配下，正确配体和完全错误配体得分相同。

这是一项确定的联合目标维度缺失，不是说 DockQ 本身错误。**当前“best”只表示蛋白界面最优，不能作为三元装配整体最优的充分依据。**

**优先诊断：** 直接对照已有 `best_model.pt` 与 `best_loss_model.pt` 的 PP DockQ、两个配体界面、晶体配体 RMSD 和全原子合法率；无需为此先启动新训练。保留 PP benchmark，并另外明确联合任务的选择准则。

### I. 新确认：解码器不保持执行器的旋转键等价表示

位置：`models/assembly.py:334–348,382–402,406–432`；片段选择见 `diffdock/utils/torsion.py:25`。

对一根键交换端点 \((u,v)\to(v,u)\)，同时把旋转片段 mask 取补，不是改变了分子，而是改变了描述同一内部运动的方式。在当前 horizontal gauge 下，两种表示的正向物理切向量相同。

设轴为 a，原始扭转速度为 w，中心化坐标为 x。交换后原始速度相差一个全分子的刚体旋转；去自旋的结果满足：

\[
w'=w-a\times x,\qquad
\omega'=\omega-a,
\qquad
w'-\omega'\times x=w-\omega\times x.
\]

代码的半轴 ridge prior 也保持此等价性。然而 controller 同时使用有序的端点特征拼接、有向轴投影、按顺序拼接的两侧片段表示、原始 mask 共享比例以及有向轴点积。这些量没有被对称化，网络结构不保证两种表示预测相同的物理动作。

**实际解码器反例，主审独立复现：** `torch.manual_seed(7)`，先构造 float64 `LegalPoseDecoder(width=16,channels=4)`，再依次生成随机 h、v、12节点坐标，节点为3 E3＋3 POI＋6 ligand。配体坐标覆写为：

```text
[(0,1,.3),(-1,0,0),(0,0,0),(1,0,0),(2,1,1),(3,1,0)]
bond=(2,3), mask=[0,0,0,1,1,1]
两侧专家 torsion evidence=0；state 的 t=.5、dt=.05、其余项为0
```

保持所有节点证据不变，仅交换轴端点并取补 mask：

```text
horizontal tangent 最大差 = 1.6653e-16
原表示 decoder torsion = -0.002734079725
反表示 decoder torsion = -0.008517865046
实际非零切向量原子数 = 6，mask 标记原子数 = 3
```

**这是架构缺少等价表示不变性的证据，未证明训练后误差大小。** 在等大小片段上，当前 featurizer 根据图遍历顺序决定旋转侧，重新编号原子可能触发这种表示切换，因而它不只是非法输入的问题。执行器已有的局部等价性测试不能替代 controller 的一致性测试。

同时，horizontal torsion 一般移动整个配体；用 raw mask 定义 joint attention 中的“受影响原子”和共享比例，不能直接解释成真实动作的支撑或力学耦合。网络可能学会补偿，但这增加了对参数化约定的依赖。

**验证／修正方向：** 先做完整模型的化学等价原子重编号实验。若差异显著，将端点／片段查询对称化，优先用实际 horizontal Jacobian 及其 Gram 矩阵描述动作耦合；不要仅在执行器再加补丁。

### J. 新确认：侧链构象对当前模型严格不可辨识

这比“CA 物理损失比较粗”更强：当前输入表示本身没有让模型看到实际侧链构象。

代码链路如下：

- `diffdock/datasets/process_mols.py:192–199`：receptor features 为氨基酸类别＋序列 ESM，侧链向量另存。
- `scripts/featurize_common.py:251–257`：只提取 coords、features、edges，没有保留侧链向量。
- `scripts/featurize_common.py:78–125,416–417`：另生成32维 backbone／侧链／χ角 `local_geometry`，但当前 `tricoopdiff/` 没有任何消费该字段的模型路径。
- `models/assembly.py:810–816` 构图只传 coords／features；Matcha preparation／read 同样使用序列与 CA，没有读取该结构字段。

**严格的不可辨识构造：** 固定序列、全部 CA、配体和组分姿态，只旋转某残基侧链得到两个合法 rotamer。模型有效输入相同，因此任何权重下的预测必然相同：

\[
I(P_{\chi_1},L)=I(P_{\chi_2},L)
\Rightarrow f_\theta(P_{\chi_1},L)=f_\theta(P_{\chi_2},L).
\]

但两个 rotamer 可以分别朝向／背离配体，具有不同的碰撞和接触。增大节点宽度或增加 CA 交互层不能恢复从未输入的信息。

**修正方向：** 先把已生成的 `local_geometry` 接入独立蛋白结构投影，供条件接口和三元 controller 使用，避免改变冻结 ESM 的输入契约。若目标是精确碰撞或定向氢键，还需要局部有向几何／完整原子信息；32维标量也不是所有原子几何的完整替代。实际收益需配对实验。

### K. 新确认：规范参考帧存在不连续跳变

位置：`models/expert.py:213–217`。第一轴取最远 CA，第二轴取垂直分量最大的 CA，两次 `argmax` 都可能在近似并列时换点。

构造六个非退化 CA 点：

\[
\pm(1+\epsilon,0,0),\quad
\pm(0,1-\epsilon,0),\quad
\pm(0,0,0.3).
\]

按代码计算，\(\epsilon=10^{-9}\) 与 \(-10^{-9}\) 的结果为：

```text
输入坐标 Frobenius 差 = 4.0000001e-9
anchors = (0,2) -> (2,0)
frame Frobenius 差 = 2.8284271
规范坐标 Frobenius 差 = 2.9529646
```

第二轴没有退化，跳变来自离散选轴。冻结 Matcha 接收规范坐标并包含坐标位置编码，其 token 没有被架构保证对规范帧选择不变；手工帧向量也会同步跳变。

**结论边界：** 表示不连续已用 NumPy 独立复现，下面的真实权重诊断进一步确认了专家特征和完整模型预测对选帧的敏感性。上面的 `4e-9` 是 float64 数学构造，不能直接作为 float32 推理的可分辨扰动。anchors 在样本准备时固定，不能说 rollout 每一步都在换 anchor；同一刚性蛋白的全局 SO(3) 等变性也不因此自动失效。

**验证方向：** 对真实蛋白做极小 monomer 扰动，重新准备 anchors，分别测输入变化、token 变化和最终动作变化。可考虑多帧聚合或避免依赖硬选轴的表示；直接换 PCA 也可能遇到特征值并列和符号跳变，不能当作自动解决方案。

**实验设计。** 扫描缓存中 29 个不超过 400 CA 的蛋白实例，按“把最远点的次远竞争点推到第一轴换点边界所需的单 CA 位移”升序，选前四个实例（来自三个 case；另有三个实例因节点上限排除）。这是刻意选择的边界压力测试，不是随机样本发生率统计。先将一个 CA 人为移到临界附近，再在临界两侧各偏移 `1e-4 Å`，最终转换为实际推理的 float32，并验证 anchors 确实切换。该单 CA 形变不保证局部蛋白几何物理合理。

**模型含义与归因边界。** 不连续已经传播到冻结专家 scalar 和当前完整控制器的实际输出，并非只有规范坐标数组改变。当前三元 checkpoint 的 `global_step=1`，终点差只说明架构和这份权重存在敏感性，不能外推成熟模型的 docking 精度，也没有测 DockQ 或随机初始化成功率。`node_vectors` 显式附带 `frame.T` 三个基向量，其变化部分是设计结果，不能单独作为 Matcha 旋转等变性失败的证据；完整控制器差异包含专家 token 与这些手工向量的共同影响。JSON 中一般 `difference.rms` 是逐标量分量 RMS；只有明确标为原子 RMSD 的量才按每原子三维距离计算。控制器 translation 速度单位为 Å/归一化时间，rotation/torsion 为 rad/归一化时间；专家 `translation_head_div10` 是适配后的证据，不能解释成一步位移。

**后续修复优先级。** 将两个选轴竞争间距加入输入诊断，并用本脚本作为回归基线；优先比较多候选帧聚合或对帧选择不敏感的架构。仅给 argmax 加容差或改 PCA 不能保证连续性；单纯缓存 anchors 只能避免同一条 rollout 重选，不能解决不同输入准备之间的跳变。修复后应在较成熟 checkpoint 和真实构象集合上补测端点敏感性与 docking 指标。

### L. 新推导：E3 vector 界面项实质上是接触度重加权的坐标回归

位置：`train.py:387–396`。设配体原子误差为 \(e_j=L_j-L_j^*\)，E3固定，目标接触对数为 M，配体原子 j 的接触度为 \(d_j\)，误差尺度为 s。则：

\[
(L_j-E_i)-(L_j^*-E_i)=e_j,
\qquad
\mathcal L_{\mathrm{vec,E3}}
=\frac1{3Ms^2}\sum_j d_j\|e_j\|^2.
\]

所以这个项没有增加独立的相对构象约束，而是在整体 ligand MSE 之外按 CA 接触数再次加权。同样大小的原子误差，接触度20与1时在此项中的贡献相差20倍。

“两侧分别取 mean”平衡的是两侧总量，不平衡侧内原子，更不等于按化学重要性平衡两个结合端。接触密集片段可能被重复强调；是否恰好有利于 warhead 需要核查，不能仅凭损失名称判断。

POI–ligand vector 项则约束 \(\sum_{(i,j)}\|e_j^L-e_i^P\|^2\)，具有真正的两组分相对误差含义。它单独存在共同平移零模，但全局坐标项已消除该零模，不能把整个目标写成欠定。

**诊断方向：** 按 warhead／linker／其他片段统计接触度和梯度贡献，再判断是否需按原子先聚合、或按结合端化学角色加权。

### M. 新推导：等权 vector＋distance 实际产生径向／切向4:1的局部权重

位置：`train.py:395–398`。vector 误差对 xyz 分量取 mean，分母为3M；distance 误差分母为M。设单接触目标向量为 r，单位方向为 n，小误差为 e：

\[
\|r+e\|-\|r\|=n^\top e+O(\|e\|^2),
\qquad
\mathcal L(e)\approx
\frac{\|e\|^2}{3s^2}+\frac{(n^\top e)^2}{s^2}.
\]

该局部二次型径向系数为 \(4/(3s^2)\)，两个切向系数均为 \(1/(3s^2)\)。因此它不是两项同等强度的重复约束，而是显式偏重接触线方向。

对实际 loss 函数提取的数值实验：E3 CA=(0,0,0)，目标 ligand=(2,0,0)，误差为0.001 Å，径向组合 loss 为1.3333333e-6，切向为3.3333340e-7，约4倍。主审也独立检查了该二次型特征值。

**边界：** 多个接触方向的叠加会改变整体各向异性，不是每个真实界面都固定4:1。偏重距离可能有合理目的，尚不能称它损害预测；但应明确这个隐式权重，而不是认为当前 loss 对空间方向等权。

### N. 新推导：整体坐标 MSE 对刚体自由度的权重取决于蛋白惯性矩

位置：`train.py:756–757`。所有坐标都用1 Å尺度，不意味着平移、旋转以及不同大小蛋白的动作误差权重相同。

设 POI 已中心化，\(C=N^{-1}\sum_iq_iq_i^\top\)，只有绕单位轴 u 的旋转误差 \(\theta\)。则坐标 MSE 精确为：

\[
\mathcal L_{\mathrm{rot}}
=\frac{2(1-\cos\theta)}{3s^2}
\big(\operatorname{tr}C-u^\top Cu\big).
\]

局部旋转 Hessian 为：

\[
H_{\mathrm{rot}}=\frac2{3s^2}
\big(\operatorname{tr}C\,I-C\big).
\]

因此相同角度误差在均方横向半径20 Å与5 Å的结构上可相差16倍；细长蛋白绕长轴／横轴也具有不同权重。远离界面的结构域会通过惯性矩改变训练的旋转偏好，即使局部结合界面相似。这是动作空间中的隐式预条件，不能用“对原子取 mean”消除。

此外，沿固定轴的角度梯度与 \(\sin\theta\) 成比例，在180°处为零。对称四点实验中该子项 loss=1.33333333，但角度导数约8.16e-17。它说明大角度粗定位的坐标回归地形并非处处提供强旋转梯度。

**边界：** 任意形状的180°旋转不一定在所有轴向变化上都是驻点；其他接触项及网络参数化也可能打破停滞。不能据此声称完整训练必然卡在180°，更不能笼统宣称远场平移梯度消失。

**诊断方向：** 按起始旋转误差、蛋白惯性矩与界面尺寸分桶，检查 rollout 改善率及各自由度梯度贡献。若证实尺度偏置与失败相关，再讨论界面优先或明确的 SO(3) 姿态辅助目标；不建议直接用蛋白半径归一化替换所有坐标损失，避免重新削弱界面误差。


该实验隔离了权重恢复，只验证入口如何消费恢复后的计数和数据。轮末保存的 checkpoint 不触发此轮内问题。

**建议：** 保存本轮具体 entries、下一批 cursor 及必要的统计累计值；恢复后消费剩余批次。否则应明确标记轮内 checkpoint 为非精确恢复，不能宣称恢复了完整训练轨迹。增加入口级中断／恢复对照，现有“下一 optimizer update 相同”的单元测试不足以覆盖数据循环。

### 7. P2：ESM 特征缓存身份遗漏实际编码器

位置：`scripts/featurize_common.py:60–75`；实际模型选择在 `:182–187`。

`_featurize_signature` 散列源结构和 `score_model_args`，但生成 ESM 特征时还会读取 `TRICOOPDIFF_ESM_MODEL`。该模型的配置、tokenizer 和权重身份没有进入缓存签名。

**触发条件：** 复用缓存目录，同时切换同维度 ESM 编码器，或更新同目录内的权重。旧缓存仍被接受，新生成的缓存却使用新模型，可能形成来源混杂的特征集。

**已复现：** 用 AST 提取实际签名函数，保持输入文件及参数不变，仅将环境变量从模型 A 改为 B，得到 `ESM model changed but signature identical: True`。没有加载模型或下载权重。Matcha metadata 对已有 feature cache 文件的散列不能纠正该文件本身的过期来源。

**建议：** 缓存身份包含实际编码器的配置、tokenizer 和权重摘要，而非只包含路径；同目录内容更新也应使缓存失效。

**边界：** 未证明当前训练资产已经混用 ESM 编码器。这是条件性缓存污染与实验复现风险。

### 8. P2：cached-only 在无 cluster 索引上崩溃

位置：`scripts/train_entry.py:752–757`；索引解析见 `:164–188`。

`_load_index` 支持 list 索引及不含 `clusters` 的 dict，此时返回 `clusters=None`。普通 loader 也有无 cluster 分支，但 `cached_only=True` 无条件执行 `len(self.clusters)`，之后还会遍历它。

**已复现：** 用实际代码的 AST 函数／类构造临时 list 索引，一条合法输入记录及对应已有 `.pt` 文件，初始化 loader 得到：

```text
TypeError: object of type 'NoneType' has no len()
```

**建议：** 无 cluster 时只过滤 entries；cluster 统计与过滤放到显式存在 cluster 的分支。

**边界：** 正式带 cluster 的 DeepTernary 索引不触发；这是已支持索引格式与选项组合之间的兼容性错误。

### 9. P2：POI 接触诊断把数量相等当作对应已验证

位置：`tricoopdiff/evaluate.py:283–318`，`compute_poi_dockq`；调用处为 `evaluate_model`。

函数只检查 ligand 和 POI 的坐标行数，然后按行号计算 native 接触恢复，并返回 `atom_correspondence=True`。没有传递或校验配体原子身份、POI 残基身份及重排映射。

**已复现：** native ligand 为 `[[0,0,0],[20,0,0]]`，POI 为 `[[0,0,1],[20,0,1]]`。mock native 解析后调用实际函数，原顺序得到接触恢复 1.0；仅交换 POI 两行，空间点集没有改变，结果变为 0.0，且仍标记 `atom_correspondence=True`。

该复现说明接口无法区分“有已知对应的坐标误差”与“身份被重排”，并非要求有身份的接触矩阵在任意重排后自动不变。

**建议：** 显式传递和验证原子／残基映射；只有数量相同但无法证明对应时，不应标记已验证对应，可仅输出无对应的密度诊断。

**边界：** 同源同序的标准 bound 模板未被证明受影响；外部输入、重排模板或等长但对应不同的模板会触发。蛋白全原子主 DockQ 不调用此函数，不受此缺陷直接影响。

### 10. P2（历史辅助路径）：物理修复拉坏共价键且返回旧检查结果

位置：`tricoopdiff/geometry/reflect.py:331–352`，`local_minimization`；`:411–418`，`tricoop_reflect`。

碰撞检测按化学图排除近邻共价原子，但修复时的排斥力对所有原子计算，包含共价邻居。修复后仅重新计算碰撞，没有重新计算键长异常，返回的 `bond_anomalies` 及相关有效性判断可能与最终结构不符。

**已复现：** 三个碳原子的坐标为 `[[0,0,0],[2.30,0,0],[0.5,0,0]]`，仅 `(0,1)` 为单键。默认修复后该键长变为 2.6741 Å，超过代码阈值 2.31 Å；返回 `n_bond_anomalies=0`，对输出重新检查得到异常数 1。

**建议：** 修复力排除相应拓扑近邻，并对最终输出重新执行全部有效性检查。自由原子位移还可能改变其他内部几何，长期应明确修复器的几何约束。

**边界：** 仓库检索仅发现测试调用该辅助函数，未发现生产训练／采样调用；不能将其作为当前模型效果不佳的原因。
